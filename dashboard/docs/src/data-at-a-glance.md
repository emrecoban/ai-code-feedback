This table lists every data item of the system. It includes the values that the extension and the server store, the metrics that the dashboard computes, the database functions, and the instruments that are measured outside the extension.

Click a name to open the page that explains it. Technical fields, such as ids and time stamps, are explained on the table reference pages. The research stage says when a study uses the item: design, baseline, during the intervention, post-test, analysis or reporting.

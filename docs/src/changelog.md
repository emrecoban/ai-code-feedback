# Metric changelog

Every derived metric has a formula version. Version 1.0 is the formula as it is in the code of extension 0.2.0 and in database migrations 0001 to 0024. When a formula changes, for example a threshold or a time window, add a new version here. Say what changed and whether values from the old and the new version can be compared.

# Registro de cambios de métricas

Cada métrica derivada tiene una versión de fórmula. La versión 1.0 es la fórmula tal como está en el código de la extensión 0.2.0 y en las migraciones de la base de datos 0001 a 0024. Cuando cambie una fórmula, por ejemplo un umbral o una ventana de tiempo, añada aquí una versión nueva. Indique qué cambió y si los valores de la versión antigua y de la nueva se pueden comparar.
